about | how it's made

I have never been satisfied with the look of my website. I've always been drawn to simple, minimal pages, but I've struggled to find a design that feels like my own.

Under the hood, the implementation is deliberately kept simple: static HTML and CSS, no JavaScript framework, and a domain registered and hosted on Cloudflare. I write HTML and CSS locally on my machine, when changes hit main a CI pipeline pushes them to Cloudflare Pages.

I chose the name Saturn because it's my favorite planet. It has rings!

evolution | version history

Feeling nostalgic, I decided to go through the previous evolutions of my site's design. It was easy to do, since the entire history of the website (back to my first commit in 2021) exists in this repository.

  1. Nov 2021 16294c0

    I like food and building stuff

    This was my first website, two days after my first commit. It had one HTML file and one stylesheet, used Lato from Google Fonts, and was hosted on GitHub Pages. At the time, I was learning how to write HTML and CSS, figuring out how hosting worked, and trying to decide what a personal site should be. I remember feeling proud that I had a website, and proud that I built it myself. I still feel proud.

  2. Jan 2022 0042771

    create-react-app

    You know what proves you're a real software engineer? Rebuilding your static four-page website in React. I remember thinking at the time, "Oh yeah, baby! This is what real developers do." It used React 17 and TypeScript, and came with a 120,000-line package-lock.json. Of its five routes, four rendered the same 'coming-soon' page. Addtionally, If you hover over one of those boxes, they turn pink! If you ever hear me tell someone I am good at design, feel free to bring this up for discussion.

  3. Apr 2022 6ce6c78

    Back to plain HTML

    Thankfully, I must've encountered motherfuckingwebsite sometime in early 2022. I got rid of React and went back to vanilla HTML and CSS. Unfortunately, I still didn't know how to make a real website landing page look great. So, while the React app was out, I replaced with this beauty: two hand-written pages set in Unica One and Open Sans. This stayed up until September 2023.

  4. Jun 2026 3a04d67

    Clean slate

    After a few more redesigns between 2023 and 2026, I felt I needed to reset my CSS in order to find the design I truly wanted. It was tagged as v0.2.0 in the changelog. Initially, everything was lowercase and monospace (which got annoying), set in Ioskeley Mono. I then added a now page, a grey-green background, a garden page, and a PGP key. I appreciate this version for being short lived, and for setting me on my current path.

which brings us to now

There's an old misquote: "A good artist borrows, a great artist steals." I never learned design, but I did learn how to steal.

The current iteration of the site is set in Geist Pixel, which I mercilessly ripped from royfish.dev after reading their excellent Fingerprints are the new cookies post.

I visited Ruby Morgan Voigt's blog some time ago. Their old site picked a new color theme on every page load. I loved it, and added themes to this site using several color combinations from the theme Flexoki by Steph Ango. The theme switcher in theme.js was written by an LLM. I’m counting that as stealing too.

I have also taken code and ideas from these sites and developers, and probably others I've forgotten:

  • vale.rocks
  • textlog.cc
  • catskull.net
  • motherfuckingwebsite and its derivatives, like modernmotherfuckingwebsite

Thank you all.

I don’t know if this site is better than the first version. I’ll probably want to redesign it again someday soon. But like that first one, I made it, I like it, and I’m proud of it.
