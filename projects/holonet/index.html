about | how its made

Holonet is an open-source backend for multiplayer games, written in Go. It comes in two halves. The control plane is a plain HTTP API for things like registering and logging in. The data plane is where the game actually runs: server-authoritative world servers that talk to players over WebSockets.

The first milestone is v0.1.0, a world that ticks with a Godot client connected to it. Before that I need config, logging, the login endpoints, the WebSocket server and the tick loop itself, then a Godot addon to hook up a small Zelda clone. I'm aiming for the end of October.

It's very early days. The commits up top are the best way to see where it's at.
