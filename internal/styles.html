rules

  • Lime (--accent) is for navigation and things you can act on. Labels, headings in footers and metadata stay grey.
  • All caps come from CSS: the caps selector list at the end of global.css, or the .caps utility. Write the HTML in normal case.
  • Only unclassed links inside p, li, td, dd, blockquote and figcaption get the underline and highlight. A link with a class styles itself.
  • Internal links end in a slash: /now/sep-2026/.
  • Public pages allow no inline styles (style-src 'self'). Only internal/ pages, like this one, use them.
  • No JavaScript on the site. The two lines at the bottom of this page are the only exception, and this page is never deployed.

post

A post is an article holding a .page-header--post, which turns it into the panel. The likes and comments block is written by functions/_middleware.js; the markup below copies what it outputs. A .pager straight after the article sits 1rem under it. An optional .post-banner photo can open the panel: 2:1 (4:3 on phones), bled to the panel edges, linking to the photo's page. .post-banner--row (a figure, no link) holds several photos side by side, as on /about/. On phones the panel and pager cards run edge to edge.

.photo-wall / .photo-tile / .photo-tile--new (hover a tile for its caption)

The .lightbox opens on :target, with no JavaScript. It covers the whole screen, so it isn't shown here; see /photos/ and the tracker walls. On /photos/ each lightbox shows the photo's name and a .lightbox-details link to its page.

Each photo has a page at /photos/<file name>/: .photo-entry puts the whole photo beside an .entry-heading (title, date, place, camera, film), stacked on phones. Clicking the photo opens a single lightbox, #full. Posts and banners link here, never to #view-….

.img-scaled caps an image's height (26rem, or --short 18rem, --medium 24rem, --tall 30rem) and centres it.

responsive

  • ≤ 900px: photo wall drops to two columns.
  • ≤ 768px: less page padding, h1 1.6rem, project cards stack. Paragraphs stop using text-wrap: pretty.
  • ≤ 600px: header stacks with the nav on one row and "home" hidden; meta-split, tables, project stats, entry hero and the pager stack; a .post-banner--row keeps its middle photo; the footer drops // and PGP.
  • ≤ 480px: 1rem page gutter; h1 1.5rem, h2 1.2rem, h3 1.05rem; the post panel and pager cards run edge to edge; photo wall one column, tracker walls two; the footer also drops changelog.

preferences

  • prefers-reduced-motion: transitions and animations are effectively turned off.
  • prefers-contrast: high: white text, yellow accent, white borders, underlined links.
  • print: black on white, nav and pager hidden, URLs printed after links.
